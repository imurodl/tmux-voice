Talk the way you think

Most of us don't think in one language. The language is detected on every recording, so switching mid-sentence just works. These are real transcripts from the test recordings, unedited.

What happens when you let go

A small local daemon does the work. Hammerspoon catches the key; nothing runs in the cloud except the transcription itself.

  1. 1

    Record

    While you hold the key, the mic records. Press any other key to cancel.

  2. 2

    Learn the words

    Your repo, branch, changed files, dependencies and SSH hosts go along as key terms.

  3. 3

    Transcribe

    ElevenLabs Scribe v2, with Gemini 3.5 Transcribe as automatic fallback.

  4. 4

    Place it

    Into the active tmux pane without pressing Enter, or the pane you named: "Codex, …".

  5. 5

    Hear back

    When the agent finishes a turn you spoke, its first sentence is read aloud.

Small things that matter daily

Text, not a send button

Nothing is submitted for you. Read it, fix a word, press Enter. Optionally end with "send it".

Works outside the terminal

With Slack or a browser in front, the text is typed there instead.

Fixes the usual mishearings

"cloud MD" becomes CLAUDE.md. "Cloud, run the tests" goes to Claude. Add your own rules.

Status where you look

A red REC and an amber STT in the tmux status line and the menu bar.

Recovers on its own

A watchdog restarts the daemon if it ever stops answering.

Knows what it costs

tmux-voice usage shows minutes spoken per day and the estimated bill.

Set it up in five minutes

  1. Clone and run the installer. It installs what's missing (tmux, uv, Hammerspoon) after asking, and asks for an ElevenLabs or Gemini API key.
  2. Turn on Hammerspoon in System Settings → Privacy & Security → Accessibility, then quit and reopen it.
  3. Hold Right Option, say something, release. Allow the microphone once.

Every edit to your configs is marked and backed up, and ./uninstall.sh removes it all. macOS only for now.

Cost: about $0.27 per hour of speech on Scribe v2. A heavy coding day is 30–60 minutes of talking, so a month of daily use is roughly $3–6.

Your agent subscription: barely affected. A spoken prompt adds a few dozen tokens to turns that process tens of thousands.
